# Quantum Computing Laboratories

Interactive Qiskit laboratories for **M34099 Quantum Computing** at the University of Portsmouth.

These notebooks help students move from quantum-computing theory to practical circuit construction, simulation and experimentation with real IBM quantum hardware.

## How to Use the Notebooks

1. Select the laboratory below.
2. Click **Open in Colab**.
3. Sign in to Google if requested.
4. Select **File → Save a copy in Drive** to retain your work.
5. Run the notebook cells in order.
6. Complete the simulator activities before using IBM quantum hardware.

## Execution options

Each laboratory provides two execution routes:

- **Qiskit Aer simulator:** available to all students and used first.
- **IBM quantum hardware:** available through the module's IBM Quantum Classroom account.

## Security notice

Never enter an IBM API key into a visible notebook cell. Never upload API keys, passwords, classroom credentials or personal information to GitHub.
